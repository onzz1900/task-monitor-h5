# 任务流转中心 · 流转时刻轴（Mission Transfer Center — Timeline Edition）

同一个产品的**第二套视觉设计**：电商采集、监控与报表任务的点位进度与流转时间。
与官方原型（`variants/ops-console/`，密集深色控制台 + 表格 + 右侧抽屉）不同，这一版是
**暖纸质浅色底 + 衬线标题 + 单列「流转时刻轴」**，任务卡挂在时间轴上，详情用居中弹层（窄屏为底部抽屉）。

## 预览

在**本目录**下启动静态服务：

```bash
cd variants/transfer-center-v2
python3 -m http.server 4174
```

然后打开 http://localhost:4174/ 。

纯静态页面，无需登录、无后端、无构建步骤。

## 这一版长什么样

- **顶栏**：品牌 + 数据快照时间 + 浅色 / 深色切换（偏好写入 `localStorage`，键名 `mtc-v2-theme`）。
- **概览区**：左边一块大号「最近一次流转」倒计时（超时会变红并改写标题），右边四张统计卡
  —— 运行中 / 待流转 / 已阻塞 / 本轮已完成，每张带一个占比圆环。
- **筛选**：状态胶囊 + 搜索框（可搜任务名、点位分组、负责人、运行结果）。
- **流转时刻轴**：按下次流转时间排序，按天分组。宽屏左侧是时间槽（时刻 + 相对时间），
  窄屏时间收进卡片顶部。每张卡显示状态、类型、编号、任务名、当前动作、
  **点位进度（`12/20` + 分段点位条）**、**上次运行结果（成功/失败 + 具体数字）**。
- **任务详情**：点卡片打开，只放该看的四件事 —— 下次流转时间、最近运行时间、上次运行结果、
  点位概要（分组进度 + 备注），外加负责人与当前动作。`Esc`、点遮罩或右上角 ✕ 关闭。

## 文件

| 文件         | 作用                                             |
| ------------ | ------------------------------------------------ |
| `index.html` | 页面骨架、顶栏、概览区、筛选与时刻轴容器         |
| `styles.css` | 全部视觉（浅 / 深主题变量、时刻轴、卡片、弹层）  |
| `data.js`    | 中文电商模拟数据（任务、点位分组、人员、快照时间）|
| `app.js`     | 主题切换、统计、时间计算、筛选、渲染、详情弹层   |

## 数据说明

`data.js` 里的 `now` 是固定的数据快照时间（`2026-08-18T09:42:00+08:00`），
所有「x 分钟后 / 已超时 x 分钟」都以它为基准换算，因此原型每次打开显示都一致。
时间统一按 `Asia/Shanghai` 渲染。

## 不影响官方原型

本目录是**独立新增**的一套设计，没有改动 `variants/ops-console/`、仓库根目录 `index.html`
或任何归档样式目录。
