# Style B — 流转看板

嘉禾商业运营中心的任务流转工作台。打开 [`index.html`](./index.html) 即可查看。

## 首屏内容

- 会议统计：今日会议 2、本周会议 5、待跟进 4、已完成 1
- 任务卡片：当前状态、负责人、下次流转时间（时间数字最大）
- 桌面：按状态分列（进行中 / 流转中 / 待跟进 / 阻塞 / 完成）
- 平板与手机：看板列横向吸附滑动，下一列露出一角

## 样式要点

- 浅纸色、暖灰列，状态色克制统一，不做彩虹列
- 负责人用小号姓名，不用头像
- 卡片等高：流转时间区、两行标题、底部状态与姓名
- 纯静态页面：无图表、无登录、无后端
