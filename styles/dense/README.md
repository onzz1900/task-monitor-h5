# Style D · 高密度指挥台

静态终稿。打开 `index.html` 即可查看公司任务指挥台。无需登录，无后端。

路径：`/styles/dense/index.html`

## 首屏

- **会议统计**：今日会议 2 / 本周会议 5 / 待跟进 4 / 已完成 1
- **任务行**：状态、负责人、下次流转时间并排可见
- 流转时间独立成列，等宽数字，类似发车时刻表，是最醒目的一列
- 状态为短词 + 细色标，不用粗胶囊

## 版式

- 桌面约 1100px，行距偏紧，一次扫过 7 行
- 手机行高压缩；时间列靠右、加粗、上下分行（日 / 时刻）

本目录为并行视觉方案之一，不覆盖其他风格目录。
