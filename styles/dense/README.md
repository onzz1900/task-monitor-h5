# Style D · 高密度指挥台

静态页面，打开即可查看公司任务指挥台。

## 打开方式

直接打开本目录下的 `index.html`，或通过仓库路径访问：

`/styles/dense/index.html`

无需登录，无后端。

## 首屏内容

- **会议统计**：今日会议、本周会议、待跟进、已完成
- **任务行**：状态、负责人、下次流转时间并排可见
- 流转时间使用等宽 / 表格数字，独立成列，类似发车时刻表
- 状态用短词着色，不用粗胶囊

## 版式

- 桌面：约 1100px 宽，行距偏紧，一次扫过更多行
- 手机：行高压缩，时间列靠右加粗

本目录为并行视觉方案之一，不覆盖其他分支。
