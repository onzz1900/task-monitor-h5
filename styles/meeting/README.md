# 任务简报工作台

静态页面，打开即可查看公司内部的任务简报。没有登录，没有后台。

## 打开方式

直接打开本目录下的 `index.html`，或在本地起一个静态服务后访问：

`/styles/meeting/index.html`

## 这一页有什么

- **任务简报**：先看时间，再看人。今天要推进的任务，和下一次流转。
- **今天要推进**：按 10:30 / 14:00 / 16:30 排列的今日任务（流转时间，不是会议议程）
- **任务列表**：状态、负责人、下次流转时间（时间字号突出）
- **辅助统计**（次要）：今日会议 2、本周会议 5、待跟进 4、已完成 1

桌面端左右两栏（左：今日任务，右：任务列表），窄屏先今日任务后列表。

## 视觉

晨间任务简报气质：时间先行的排版、暖纸色、编辑感，但仍是办公工具。
