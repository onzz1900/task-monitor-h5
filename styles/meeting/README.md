# 会议日程工作台

静态页面，打开即可查看公司内部的晨间流转简报。没有登录，没有后台。

## 打开方式

直接打开本目录下的 `index.html`，或在本地起一个静态服务后访问：

`/styles/meeting/index.html`

## 这一页有什么

- **会议统计**：今日会议、本周会议、待跟进、已完成（大号数字）
- **今天要流转**：按 10:30 / 14:00 / 16:30 排列的时段议程
- **任务流转表**：状态、负责人、下次流转时间（时间字号突出）

桌面端左右两栏（左议程、右列表），窄屏先议程后列表。

## 视觉

晨间简报气质：时间先行的排版、暖纸色、编辑感，但仍是办公工具。
