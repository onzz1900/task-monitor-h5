# 任务跟踪

公司内部任务跟踪页，用来查看流转与跟进事项的当前状态、负责人和下一次流转时间。电脑和手机打开的是同一套页面：桌面更宽、列表可一眼扫完；手机全宽、信息上下排列。

单页、无登录、无后台。示例数据写在 `index.html` 里，改完刷新即可。

## 如何打开

若本机已有静态服务，直接访问：

http://127.0.0.1:5173/

自行启动：

```bash
python3 -m http.server 5173 --directory /workspace/task-monitor-h5 --bind 127.0.0.1
```

也可以用浏览器直接打开 `index.html`。

## 页面上有什么

- 标题「任务跟踪」，以及当天日期
- 一行数字：今日会议、本周会议、待跟进、已完成（由列表数据汇总）
- 任务列表，每条包含：名称、当前状态、当前动作 / 负责人、下一次流转时间
- 部分任务附一行最近结果
